# Security and Responsible Handling

This repository is currently public and contains a legacy prototype. It must not hold customer, warranty, device-identifier, account, financial, employee, or authentication records.

- Do not open GitHub issues containing customer/IMEI/contact data or credentials.
- Do not commit .env files, private tokens, production CRM samples, exported databases, or private checkpoint archives.
- Before publishing any application code, verify the destination repository's visibility, permissions and branch protections.
- Treat Excel, PDF and ZIP imports as untrusted until validated with strict bounds and trusted parsers.
- Fail closed if import classification, release evidence, dependency provenance, or source integrity is inconclusive.
- Deleting or replacing a file in Git does not remove copies from history, forks, or caches.

If a potential exposure is identified, use the account owner's private GitHub security channel; do not publish the details in an issue.
